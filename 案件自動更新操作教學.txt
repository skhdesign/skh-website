SKH DESIGN｜案件資料夾自動更新操作教學
========================================

一、這個版本能做什麼
--------------------
以後新增作品，不需要自己建立 HTML。

你只需要：
1. 雙擊「新增案件資料夾.bat」
2. 修改 info.txt
3. 將照片放進案件資料夾
4. 雙擊「更新作品.bat」
5. GitHub Desktop 執行 Commit、Push origin

系統會自動：
- 讀取案件文字
- 讀取照片數量
- 建立作品詳細頁
- 建立照片縮圖列
- 建立大圖 Lightbox
- 新增首頁作品卡
- 新增作品總覽卡片


二、第一次新增案件
------------------
1. 在網站主資料夾找到：
   新增案件資料夾.bat

2. 雙擊開啟。

3. 輸入案件資料夾名稱，建議使用英文小寫與連字號，例如：
   sanxing-house
   luodong-villa
   jiaoxi-hotel

4. 系統會自動建立：
   projects-data\sanxing-house

5. 建立完成後，案件資料夾會自動開啟。


三、照片怎麼放
--------------
在案件資料夾內放：

cover.jpg
01.jpg
02.jpg
03.jpg
04.jpg

規則：
- cover.jpg：首頁封面，也是作品頁第一張照片。
- 01.jpg、02.jpg：依數字順序顯示。
- 可以有任意張數，不限定 3 張或 10 張。
- 支援 JPG、JPEG、PNG、WEBP。
- 若沒有 cover.jpg，系統會使用排序後的第一張照片當封面。

建議尺寸：
- 長邊約 1920px。
- 單張約 300KB～1MB。
- 不建議直接放入手機或相機原始的 5MB～20MB 照片。

新增照片：
- 直接多放一張 05.jpg。
- 再次雙擊「更新作品.bat」即可。

刪除照片：
- 從案件資料夾刪除該照片。
- 再次雙擊「更新作品.bat」即可。

調整照片順序：
- 修改照片檔名。
- 例如把 05.jpg 改成 02.jpg。
- 檔名不能重複。


四、info.txt 怎麼修改
---------------------
請使用 Windows 記事本或 Visual Studio Code 開啟 info.txt。

範例：

發布：是
網址代號：sanxing-house
排序：1
案件名稱：三星．山景別墅
英文名稱：SANXING HOUSE
完成年度：2026
類型：住宅
座落位置：宜蘭縣三星鄉
基地面積：約120坪
建築面積：約82坪
樓層：地上3層
結構：RC
案件狀態：已完工
首頁顯示：是
案件介紹：本案以山景與田園環境作為空間配置的主要方向。
透過庭院、露台與大面開口，引入自然採光與通風。


五、每個欄位的意思
------------------
發布：
- 填「是」：會出現在網站。
- 填「否」：暫時隱藏，不會產生網站頁面。

網址代號：
- 只能使用英文小寫、數字、連字號。
- 正確：sanxing-house
- 錯誤：三星住宅、Sanxing House、sanxing_house
- 發布後不建議隨意修改，否則網址會改變。

排序：
- 數字越小，作品越前面。
- 例如 1、2、3。
- 可使用 10、20、30，日後插入新案件較方便。

案件名稱：
- 網站上顯示的中文名稱。

英文名稱：
- 作品頁名稱上方的小型英文字。
- 不需要可以留空。

首頁顯示：
- 填「是」：首頁作品區會顯示。
- 填「否」：只會出現在作品總覽頁。

案件介紹：
- 可以在下一行繼續輸入。
- 空一行會形成新的段落。
- 不需要輸入 HTML。


六、修改已存在案件
------------------
1. 打開：
   projects-data\該案件資料夾

2. 修改 info.txt 或增刪照片。

3. 雙擊：
   更新作品.bat

4. 完成後打開 GitHub Desktop。


七、更新到 GitHub Pages
-----------------------
每次雙擊「更新作品.bat」後：

1. 打開 GitHub Desktop。
2. 左側會看到變更檔案。
3. Summary 輸入，例如：
   Add Sanxing House project
4. 按 Commit to main。
5. 按 Push origin。
6. 等待約 1～2 分鐘。
7. 手機重新整理：
   https://skhdesign.github.io/skh-website/


八、如何暫時隱藏案件
--------------------
不需要刪除照片或資料夾。

只要將 info.txt 改成：

發布：否

再雙擊「更新作品.bat」並 Push。


九、更新失敗怎麼辦
------------------
「更新作品.bat」視窗會顯示錯誤。

常見原因：
- 發布設為「是」，但沒有任何照片。
- 沒有填案件名稱。
- 網址代號使用中文、空格或底線。
- 兩個案件使用相同網址代號。
- info.txt 被改名或刪除。

更新結果也會記錄在：
作品更新紀錄.txt


十、重要提醒
------------
- 不要手動修改 project-auto-開頭的 HTML，下一次更新會被重新產生。
- 正確修改方式是改 projects-data 內的 info.txt 與照片。
- 不要刪除 project-auto-template.html。
- 不要刪除 generate-projects.ps1。
- 不要刪除 AUTO_PROJECTS_START / AUTO_PROJECTS_END 標記。
- 原本既有作品仍會保留；新系統產生的作品會排列在原有作品之前。
