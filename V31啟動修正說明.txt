SKH Website Manager V31 啟動修正版
==================================

上一版無法啟動的原因：
Windows 命令提示字元將 .bat 檔案開頭的 UTF-8 BOM 誤認成指令，
因此畫面出現亂碼，並把 powershell.exe 錯誤讀成 owershell.exe。

本版已將啟動檔改成：
- 純 ASCII
- Windows CRLF 換行
- 無 UTF-8 BOM
- 使用 Windows PowerShell 的完整系統路徑

正確啟動：
1. 雙擊「START-SKH-MANAGER.cmd」
   或「開啟-SKH-Website-Manager.bat」。
2. 不需要按 Enter，也不需要選擇任何程式。
3. 等待數秒，管理視窗會自動出現。

若仍無法啟動：
1. 雙擊「START-SKH-MANAGER-DIAGNOSTIC.cmd」。
2. 等視窗顯示完成。
3. 將同資料夾內的：
   SKH-Manager-Error.txt
   傳給 ChatGPT。
