SKH Website Manager V30 正式版
================================

這是一套 Windows 本機管理工具，不是線上後台。
不需要資料庫、後端主機、登入帳號或額外月費。

【開啟方式】
雙擊：
開啟-SKH-Website-Manager.bat

【新增案件】
1. 點左下角「＋ 新增案件」。
2. 輸入案件名稱，例如：員山．田園住宅。
3. 輸入網址代號，例如：yuanshan-house。
4. 按「建立」。
5. 左側案件列表會自動出現新案件。

網址代號規則：
- 只能用英文小寫
- 可使用數字
- 可使用連字號 -
- 不可使用中文、空格、底線

【編輯文字】
1. 左側點選案件。
2. 修改案件名稱、年份、地點、面積、樓層、結構等內容。
3. 勾選「發布到網站」。
4. 需要出現在首頁時，勾選「顯示在首頁」。
5. 按「儲存案件資料」。

【加入照片】
1. 切換到「照片管理」。
2. 點「加入照片」。
3. 可一次選取多張照片。
4. 系統自動命名為 01、02、03。
5. 選一張照片後按「設為封面」。

【產生網站】
完成案件文字與照片後，按右上角「產生網站」。

【更新 GitHub Pages】
1. 打開 GitHub Desktop。
2. Summary 輸入更新說明。
3. Commit to main。
4. Push origin。
5. 等約 1～2 分鐘後重新整理手機網站。

【錯誤處理】
管理程式發生錯誤時，會在同資料夾建立：
SKH-Manager-錯誤紀錄.txt

請將該檔案內容或畫面截圖提供給我。
